Souqrates Logo Package

This package contains the latest generated Souqrates logo files in common usage formats.

Folders:
- PNG_transparent: transparent background files, best for websites, apps, overlays, and design tools.
- JPG_white_background: JPEG versions on a white background for platforms that do not support transparency.
- WEBP: transparent web-optimized versions.
- TIFF_print: high-quality print-friendly raster format at 300 DPI.
- PDF: print/share version on a white background.
- SVG_embedded_raster: SVG container with the PNG embedded; this is not a true vector redraw, but works in many design tools.
- Preview: direct preview/latest edited screenshots.

Recommended file for most uses: PNG_transparent/Souqrates_logo_transparent_4096px.png
Recommended file for maximum quality: PNG_transparent/souqrates_exact_same_logo_gold_coin_16384px.png
